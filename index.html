Copia de seguridad

Los datos se guardan en este navegador. No es una copia segura: exporta el JSON tras cada sesión y guárdalo en Dropbox mediante Archivos o Compartir.

La importación reemplaza los datos locales tras pedir confirmación.

Almacenamiento y fotografías

Las fotografías aceptadas se reducen automáticamente a un máximo de 1600 píxeles y JPEG 76 %. Si el navegador se queda sin espacio, la aplicación avisa y no confirma el guardado. En esta prueba se utiliza localStorage, limitado; no introduzcas todavía todo el inventario real.
